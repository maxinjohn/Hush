# Changelog

Changes in v13.13.5..HEAD:

## Highlights

- **Waze Queue Reliability** — queue in Waze now survives app restarts, playlist switches, and large playlists (800+ songs). Content fingerprinting ensures the queue is always correct. *(Hush)*
- **YouTube URL Paste-to-Play** — paste any YouTube/YT Music link into search to play, open album/playlist, or navigate to artist. *(Hush)*
- **YouTube Comments** — view comments for any playing song via Player Menu → Comments. *(Hush)*
- **Crossfade Speed Fix** — crossfade timing now works correctly at non-default playback speeds (1.5x, 2x). *(Hush)*

## Waze Bridge

- **Queue always correct after restart** — shim uses content fingerprinting (track IDs + titles) instead of just revision numbers to detect queue changes. MusicService restart no longer causes the shim to silently drop queue updates. *(Hush)*
- **Persisted queue revision** — `wazeQueueRevision` stored in SharedPreferences with 10,000-step headroom so the counter never goes backwards across service restarts. *(Hush)*
- **Queue change notification** — `notifyChildrenChanged("hush_queue")` called when queue fingerprint changes, forcing Waze to re-query the full track list instead of showing stale cached data. *(Hush)*
- **Debounced notifications** — 500ms debounce on `notifyChildrenChanged` to avoid spamming Waze with rapid queue updates. *(Hush)*
- **Single-item queue auto-sync** — when the queue has only 1 item (e.g., playing from search), a sync command is sent to Hush to populate the full queue before displaying. *(Hush)*
- **Deezer connection fix** — `onBind()` now returns `super.onBind(intent)` as fallback for unknown intent actions instead of `null`, fixing "can't connect to Deezer" errors. *(Hush)*
- **Shim signing fix** — release signing config guarded by `hasReleaseSigningConfig`, falling back to debug key gracefully when properties are missing. Prevents "signature mismatch" errors on reinstall. *(Hush)*
- **Build script re-signs shims** — `build-release.sh` now re-signs all 3 shim APKs through `resign-release-apk.sh` (zipalign + apksigner v1/v2/v3), matching the main app's signing pipeline exactly. *(Hush)*
- **Version code synced** — shim `versionCode` always matches the main app to prevent Android update rejection. *(Hush)*
- **Stale asset zip synced** — `waze-shims.zip` in both `main/assets` and `mobile/assets` now kept in sync. *(Hush)*

## Player

- **Crossfade timing at non-default speeds** — `adjustedDuration` now scales by `playbackParameters.speed`, so crossfade blend duration stays consistent at 1.5x, 2x, and other playback speeds. *(Hush)*
- **YouTube song skipping fix** — improved mid-playback error detection and stream URL recovery for HTTP 403/404/410 errors. *(Hush)*
- **Proactive URL refresh** — background coroutine polls stream URLs before expiry, preventing mid-song failures. *(Hush)*

## Search

- **URL paste-to-play** — paste a YouTube/YT Music link into the search field and it plays the video, opens the album/playlist, or navigates to the artist directly. Supports `watch?v=`, `youtu.be/`, `playlist?list=`, and `/channel/UC...` URL patterns. New `YouTubeUrlParser.kt` utility. *(Hush)*

## YouTube

- **YouTube comments section** — view comments for any playing song via Player Menu → Comments. Full comment list with author avatars, timestamps, like counts, and heart indicators. Infinite scroll for pagination. `CommentsPage.kt` parser handles both modern (entityBatchUpdate mutations) and legacy (commentThreadRenderer) YouTube comment formats. `YouTube.comments(videoId, continuation)` API using the WEB client. *(Hush)*

## Settings

- **Waze Integration — Uninstall button** — "Uninstall" button now appears when `ORIGINAL_APP_INSTALLED` state is detected (e.g., real Spotify/Deezer installed), and for `BUNDLED_APK_MISSING`/`BUNDLED_APK_INVALID`/`UNKNOWN` states when bridge is installed. Previously only showed static text with no action. *(Hush)*

## Build / CI

- **Waze shim signing config** — `waze-shim/build.gradle.kts` release signing config now uses `hasReleaseSigningConfig` guard with proper fallback to debug key. *(Hush)*
- **`build-release.sh` shim re-signing** — added `resign-release-apk.sh` step for all 3 shim APKs after compilation, ensuring v1/v2/v3 signature consistency with the main app. *(Hush)*
- **Asset zip synchronization** — `waze-shims.zip` in `mobile/assets` now synced from `main/assets` during build. *(Hush)*

## Housekeeping

- Version bumped to 13.13.6 (versionCode 167, app + waze-shim). *(Hush)*
- Brace balance verified for MusicService.kt (1805 pairs) and WazeIntegrationService.kt (275 pairs). *(Hush)*
- Unit tests pass (all green). *(Hush)*
