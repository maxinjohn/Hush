# Changelog

Changes since v13.13.0:

## Highlights

- **Waze off TV** — Android TV builds no longer ship the Waze bridge shims or support: TV APKs are ~1 MB smaller, drop the Waze service, and hide the Waze integration settings. Waze stays fully supported on mobile. *(Hush)*
- **Playback wakelock and locale fixes** — several lint-level crash and correctness bugs fixed (details below).

## Build

- Version bumped to 13.13.1 (versionCode 162). Waze bridge shims bumped to 13.13.1 (versionCode 163). *(Hush)*
- Waze shim APKs are now copied into `app/src/mobile/assets` (mobile-only) instead of shared `src/main/assets`; CI workflows and release scripts updated to match. *(Hush)*

## Waze Bridge

- **TV builds exclude shims** — `WAZE_SUPPORTED` buildConfigField is `true` only for mobile flavors. `MusicService`, `App`, and settings gate all Waze logic on it; `WazeBridgeManager.supported()` reflects the flag. The `waze-shims.zip` asset is bundled only in mobile builds. *(Hush)*
- **Receiver flag fix** — broadcast receivers in `WazeIntegrationService` and `MusicService` use `Context.RECEIVER_EXPORTED` explicitly (implicit intent filtering on Android 13+). *(Hush)*

## Playback

- **Wakelock lint** — confirmed the playback partial wakelock (`Hush:Playback`) is requested only while playing and always released in `onDestroy`; the "acquire without timeout" warning is expected for a music player and unchanged. *(Hush)*

## Fixes

- **`removeLast()` crash fixed** — `PulseMatrixCanvas` used the API-35+ `MutableList.removeLast()` (minSdk 26); now uses `removeAt(lastIndex)`. *(Hush)*
- **Launch `exported` fixed** — the TV `MainActivity` manifest declared no `android:exported`; set to `true` for the launcher intent. *(Hush)*
- **Stale string captures fixed** — `MusicRecognitionScreen` and `HistoryScreen` string snapshots were `remember`ed without a key; now keyed on `context` so they refresh on configuration change. *(Hush)*
- **Unremembered states fixed** — `PlaylistSuggestionSection` created `mutableStateOf` fallbacks during composition without `remember`; now remembered. *(Hush)*
- **Nav back-stack entry fix** — `MusicRecognitionScreen` retrieves its `NavBackStackEntry` with the correct entry key instead of a plain `remember`. *(Hush)*

- **Formatter locale fixes** — `DebugSettings`, `LyricsSettings`, `PlayerMenu`, `Preference`, and `AlarmSettings` now format numbers with an explicit locale (`Locale.US` or the composition-aware locale) instead of the implicit default. *(Hush)*

## Localization

- **`max_selection_limit` placeholders** — all 19 locale files now include the `%1$d` argument required by `stringResource`. *(Hush)*
- **Hebrew plural sets** — added the "many" quantity for Hebrew plurals; fixed the unescaped `%` in two Hebrew percent strings (would crash `String.format`). *(Hush)*
- **Other plural fixes** — German/Italian/Portuguese `n_selected` gained the "one" quantity; French/Portuguese switched `1 X` to `%d X` in seconds/minute/widget_total_plays. *(Hush)*

## Build tooling

- Removed dead `launcher_background_v31` / `launcher_foreground_v31` drawables (no `v31` resources remain). *(Hush)*
- `GlobalLog` no longer uses a cached SimpleDateFormat; it formats per call with `Locale.US`. *(Hush)*
- `TvUtils` uses `LocalConfiguration` (composition-aware) instead of a raw `Configuration`. *(Hush)*
- `WheeWallClock` const: removed unused variable. *(Hush)*
