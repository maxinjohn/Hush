# Changelog

Changes in v13.14.7..HEAD:

## Highlights

- **The source list is pluggable end to end** — **Audio Sources → Repositories** lists every address Hush reads (the two registries it ships, the BitChord module index, anything you add) with what each declares, whether it is being fetched and one switch. A paste is fetched before it is stored, so a typo cannot leave a dead row behind, and a browser link (`blob`, `raw`, a bare repository page) is resolved to the file it names. *(Hush)*
- **BitChord's modules play** — the module index's sources run in this app's own sandbox and are walked where you put them, before a failure is reported, so a track the runtime cannot serve can still come from a module. A personal addon server is spoken to with the signature it requires, and Tido is asked exactly what LastWave asks it. *(Hush)*
- **A fresh install plays lossless without a visit to settings** — every source it can play is switched on, and so is the engine, without writing anything to storage; a source you switch off is then left out of the walk, the runtime, renewal, verification and downloads alike. *(Hush)*
- **Lossless from a DASH source can be seeked** — the FLAC inside the fragmented MP4 is spliced out into a real `.flac`, so a drag on the seek bar lands instead of restarting the track. *(Hush)*
- **Home is populated before the network answers** — the last feed is kept and parsed at launch, so the shelves are on screen at ~2.9 s instead of waiting on a request that was measured at 2.6 s on its own. *(Hush)*
- **Five app themes** — **Appearance → App theme** offers Hush (the shipped look, unchanged), BitChord, Metrolist, Vivi Music and SimpMusic: radii, type, rows and navigation bar move together, while your palette and blur settings keep working underneath. *(Hush)*

## Player

- **A seek that cannot land stops spinning** — the bar holds the position you asked for, and after 1.5 s the player's own position wins, so the fetching ring goes back to play/pause instead of spinning on a track that is audibly playing. *(Hush)*
- **The transport fits the column it is in** — the row scales by the tighter of the width and height it is handed, so no button is squeezed into an ellipse on a narrow car panel or a short window, and every window that could already pay for the preset keeps it. *(Hush)*
- **The NOW PLAYING equalizer moves on every device** — the bars are advanced from frame time instead of a Compose animation the system's animator scale silences, and the same fix covers the artwork's breath, the seek thumb and the queue's playing indicator. *(Hush)*
- **The codec row is only the facts you cannot get elsewhere** — bitrate, rate, size, source; the container and the provenance phrases are gone, a playback file reads *(fetched)* instead of *(device cache)*, an in-flight transfer replaces the previous track's line, and the engine is called `3rd-party` on every surface. *(Hush)*

## SpotiFLAC

- **Two shipped addons that stopped answering are gone** — `qobuz-addon.vercel.app` (402) and `gglos.ggottes.deno.net` (404) are out of the build and out of installs that stored them; the format is untouched and one paste of a manifest address adds the next one. *(Hush)*
- **A source row is four short lines** — name, role and version, session, and the repository it came from; Test, Verify and reorder are one overflow, and an update sits under the version it answers. *(Hush)*
- **One list of twelve sources** — both shipped registries publish the same ids and the rows are merged by id, each naming the repository it came from. *(Hush)*
- **A package is installable without a published checksum** — the row says what that costs (`installed unverified`), a declared digest is still always enforced, and a package that needs a runtime feature this build does not have is refused at install with the runtime's own sentence. *(Hush)*
- **A server addon's manifest is not mistaken for a song** — a row that only offers a manifest (`dash`, `hls`) is dropped before matching and the sweep moves on, instead of downloading a 1.8 kB preview and calling it FLAC. *(Hush)*
- **Upstream renamed itself** — the engine is now **Mornye** (SpotiFLAC Mobile until v5.2.1). The pinned runtime, the signed-session protocol and all twelve registry packages were checked against it, and the build scripts name the rename instead of failing inside cargo. *(Hush)*

## Housekeeping

- Version bumped to 13.14.8 (versionCode 178). *(Hush)*
- The launch card, the car's lossless entry and the Audio Sources countdown all read the same switch and the same low-data rule, so a source that is off is not offered, renewed or counted. *(Hush)*
- `repo-list` reports `origin=added` for a repository you added and `failed=` for one that could not be read, and the semantics probe reads every window the process owns, menus included. *(Hush)*
- **A CI-only compile error is now a local one** — the release workflow copies `overlays/core` over `core` before it builds, and the overlay's `YouTube.kt` had missed the two functions the kept home feed reads back through, so `compileGmsMobileUniversalRelease` failed on references the app already used; the overlay is in step again, and `verifyOverlayParity` fails every assemble where the two trees differ, printing the `cp` that fixes it. *(Hush)*
