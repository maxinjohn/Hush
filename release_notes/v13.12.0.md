# Changelog

Changes since v13.11.9:

## Highlights

- **Playback startup rewrite** — cold start URL resolution reduced from ~15s to ~2-3s via BotGuard pre-warm at service startup, deferred `player.prepare()`, and cache space pre-warm. Prefetch await increased to 30s. *(Hush)*
- **Global download state** — a second download indicator shows aggregate progress across all songs in an album/playlist, allowing quick access to the download management screen. *(Hush)*
- **Megalobiz lyrics provider** — new HTML-scraping lyrics source for songs not found on other providers. Disabled by default. *(Hush)*
- **Low-RAM / Car Android optimizations** — player cache reduced to 128MB default, image disk cache to 128MB, Coil memory cache 16MB limit, crossfade disabled, bitmap recycling in artwork/blur utils. All scaled automatically via `ActivityManager.isLowRamDevice`. *(Hush)*
- **TV focus overhaul** — centralized `tvFocusBorder` modifier, focusable+focusGroup fixes across 15+ screens, DPad scrolling on Home/Library/Settings, carousel focus handling. *(Hush)*
- **SilentHandler crash fix** — now logs exceptions instead of swallowing them; rethrows `CancellationException` to preserve structured concurrency. *(Hush)*

## Playback

- **BotGuard pre-warm** — `BotGuardTokenGenerator.preWarm()` called at `MusicService.onCreate()` for both logged-in and anonymous sessions. `refreshPlaybackLoginContext()` fetches a fresh session if none exists. *(Hush)*
- **Cache pre-warm** — `playerCache.cacheSpace` and `downloadCache.cacheSpace` touched on `Dispatchers.IO` at startup so SQLite init + directory scan complete before first playback. *(Hush)*
- **Deferred `player.prepare()`** — URL is pre-resolved via `warmPlaybackUrl()` before ExoPlayer loads. Prefetch await increased from 1.5s to 30s. *(Hush)*
- **Removed `cancelPlaybackUrlPrefetch()`** — in-flight prefetches are no longer killed mid-work in `resolvePlaybackDataSpec()`. *(Hush)*
- **Async save on destroy** — `runBlocking` in `onDestroy()`/`onTaskRemoved()` replaced with fire-and-forget `ioScope.launch` + 2s timeout, preventing ANR during service shutdown. *(Hush)*
- **Crossfade disabled on low-RAM** — `prepareSecondaryCrossfadePlayer()` returns `null` when `isLowRamDevice == true`. *(Hush)*

## Search & Discovery (Low-End Device Optimizations)

- **Lifecycle-aware state collection** — `collectAsState()` replaced with `collectAsStateWithLifecycle()` in OnlineSearchScreen and LocalSearchScreen, stopping collection when screen is not visible. *(Hush)*
- **Local search debounce** — `LocalSearchViewModel.query` now debounced at 300ms, reducing Room queries from 4 per keystroke to 1 per pause. *(Hush)*
- **Background shuffle** — `DynamicSearchPlaceholder.shuffled()` moved to `Dispatchers.Default` so large liked-song shuffles don't jank the UI thread. *(Hush)*
- **Search crash fix** — `LocalFilter.ALL -> error("")` replaced with `R.string.filter_all`, preventing crash on ALL filter label render. *(Hush)*

## UI

- **Global download state** — `StandardPlaylistHeaderActions` gains `globalDownloadState` and `onGlobalDownloadClick` params. `HeaderDownloadState.Partial` gains `paused` field for paused-download visual state. *(Hush)*
- **Download management route** — `NavigationBuilder` registers `"downloads"` composable route pointing to `DownloadManagementScreen`. *(Hush)*
- **HomeSectionHeader focusable** — navigation title items now `.focusable()` for TV navigation. *(Hush)*
- **Spotify carousel focus** — `SpotifyPlaylistCarouselCard` now `.focusable()` for TV. *(Hush)*
- **Onboarding screen** — rewritten with TV focus support + `tvDpadScroll` + `tvFocusBorder`. *(Hush)*

## TV (All New)

- **Centralized TV utilities** — `TvUtils.kt` provides `rememberTvDevice()`, `tvDpadScroll()`, `tvFocusBorder()` with consistent 3dp primary border. *(Hush)*
- **Navigation rail focus** — `TvNavigationRail` uses `focusGroup()` on container and `focusable()` on items. *(Hush)*
- **Home screen DPad** — main LazyColumn gets `.tvDpadScroll()`. QuickPicks carousel passes DPAD_DOWN/UP to parent. *(Hush)*
- **Settings screen DPad** — full list + first-item `focusRequester`. *(Hush)*
- **Library screen focus** — `focusGroup()` on bottom filter row. *(Hush)*
- **Download management focus** — `.focusable()` on download rows. *(Hush)*
- **Search screens focus** — `focusGroup()` + `focusable()` throughout. *(Hush)*
- **Onboarding focus** — every page has first-item focus requester + tvDpadScroll. *(Hush)*
- **Settings components** — `SettingsSegmentedItem` gains `tvFocusBorder`. *(Hush)*

## Stability

- **SilentHandler rethrow** — now rethrows `CancellationException` per structured concurrency contract, preventing zombie coroutines. *(Hush)*
- **`pendingHistoryFinalizations` thread safety** — changed from `mutableMapOf` to `ConcurrentHashMap` to prevent `ConcurrentModificationException`. *(Hush)*
- **`onDownloadClick!!` safe call** — force-unwrap replaced with `onDownloadClick?.invoke()` in `PlaylistActionButtons.kt`. *(Hush)*
- **`album!!.id` crash fix** — `SimilarRecommendationsTitle` click handler uses `album?.id?.let { navigate(...) }` instead of force-unwrap. *(Hush)*
- **Force-unwrap audit** — `playlist!!.playlist.name` → `?.orEmpty()`, `artist.id!!` → `?.let {}`, `songs!!` → `.orEmpty()` across all playlist screens. *(Hush)*
- **Duplicate DataStore key** — `MixSortDescendingKey` had wrong string value `"mixSortDescending"` (was colliding with another key). *(Hush)*
- **DataStore main-thread warning** — added `Timber.v` log when preferences read on main thread before PreferenceStore is ready. *(Hush)*

## Build

- Version bumped to 13.12.0 (versionCode 160). *(Hush)*
