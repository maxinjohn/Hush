# Changelog

Changes since v13.13.1:

## Highlights

- **Upstream ArchiveTune v14.1.0 port (as 13.13.2)** — major feature sync including reactive output-device indicator, grouped download tabs, Spotify playlist download, canvas hardening, lyrics romanization upgrades, and log viewer improvements. *(Upstream + Hush)*
- **Downloads library rewrite** — new "Downloads" screen with grouped tabs (Downloaded / In Progress), search, wavy progress indicators, pause/resume/remove actions, and global download state badge in headers. *(Upstream + Hush)*
- **Spotify playlist download** — download entire Spotify playlists from the playlist header; resolves track metadata via `SpotifyPlaybackResolver` and adds to download queue. *(Upstream + Hush)*
- **Reactive output-device indicator** — live Bluetooth / USB / Headphones / Speaker icons with bitrate & sample-rate display in player header; auto-refresh on device change. *(Upstream)*
- **Canvas hardening** — `forceRefresh` support, `matchesSongIdentity` validation, `CancellationException` propagation. *(Upstream + Hush)*
- **Player theme selector fix** — V9 ("Material Extended") and V8 ("Immersive Extended") now display correctly in Settings → Player design style (previously both showed as "Expressive"). *(Hush)*

## Downloads

- New `DownloadRepository`, `ManageDownloadsUseCase`, `DownloadLibraryViewModel`, `DownloadLibraryScreen` with `DownloadLibraryTab` (DOWNLOADED / PROGRESS).
- Search filter, expandable entries, per-entry wavy progress, speed summary, pause/resume/remove.
- Header download action: toggles download state (add missing / remove completed / pause-resume partial) → navigates to In Progress tab.
- Route: `downloads?tab={tab}` (default `downloaded`); 5 playlist/album screens updated to `downloads?tab=progress`.
- Existing `auto_playlist/downloaded` (local downloaded songs) left untouched.

## Spotify

- `SpotifyPlaylistViewModel` gains `resolveDownloads()`, `events` channel, `downloadItems`/`isResolvingDownloads` in UI state.
- `SpotifyPlaylistScreen` wires download button via `StandardPlaylistHeaderActions` + `HeaderDownloadState` + `HeaderDownloadProgressIndicator`.
- New `ResolveSpotifyPlaylistDownloadsUseCase` with 8-concurrent `SpotifyPlaybackResolver.resolveToMetadata` chunking.
- `SpotifyDownloadItem(id, title)` for resolved metadata.

## Playback & Canvas

- `AudioOutputResolver` (StateFlow, API 33 `AudioDeviceInfo` + sink heuristic fallback).
- `SystemMediaControlResolver` opens system output switcher; `MiPlayAudioSupport` for Xiaomi.
- `FormatEntity` adds `RatePriority` + `autoRateDisplay()`.
- `MusicService` injects `AudioOutputResolver`, refreshes on `onAudioOutputDeviceChanged()`.
- `Queue` V7/V8: reactive `collectAsStateWithLifecycle`, focus-refresh, output switcher action.
- `HushCanvas` + `AppleMusicProvider`: `forceRefresh` param, `Cache-Control: no-cache` header, `CancellationException` propagation, `matchesSongIdentity` filter.
- New `CanvasArtworkIdentity.kt` with NFKD normalization + regex-based song/artist identity matching.

## Lyrics

- Japanese romanization restored to Hiragana→Katakana offset + map lookup (no Kuromoji dependency; APK size back to 16 MB).
- `genericRomanizationTransliterator` guarded by API 29 check.
- `normalizeLyricsText` no longer strips provider JSON blobs.

## Logging & Utils

- `GlobalLog`: cached `SimpleDateFormat` (`timeFormat`), `Timber.DebugTree` base class.
- `CipherConfigFetcher` already off-main-thread via `Dispatchers.IO` + `Mutex` (no WorkManager port needed).
- `sendRemoveDownloads` gains optional `downloads` param to only remove non-completed (upstream parity).

## Build & Housekeeping

- Version bumped to **13.13.2** (versionCode 163). Waze bridge shims bumped to **13.13.2** (versionCode 164).
- Deezer bridge label fix: removed `waze-shim/src/deezer/` from `.gitignore` (kept `amazon/`, `tidal/` ignored); `waze-shim/src/deezer/res/values/strings.xml` now tracked (`Hush-Bridge (Deezer)`); `waze-shims.zip` already contains correct labels for Spotify / YouTube Music / Deezer.
- Removed stray `* 2.xml` / `* 2.webp` build artifacts.
- Lint errors fixed: `Transliterator` API 29 guard, explicit `Locale.US` for `SimpleDateFormat`.
