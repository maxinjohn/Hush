# Changelog

Changes since v13.11.8:

## Highlights

- **Lyrics submodule update** — QRC word-timing parser, Unison 404 fix, TTML timed word segments, BetterLyrics Portato support, Paxsenix empty-payload filtering. *(Hush)*
- **Sleep timer pause fix** — `pauseFromSleepTimer()` properly cleans up crossfade, releases secondary player, and pauses both local and cast players. Crossfade is now prevented when the sleep timer is about to end. *(Hush), adapted from ArchiveTune*
- **Library crash fix** — `LibrarySongsViewModel` init block was declared before the `allSongs` Flow, causing NPE on every Songs tab open. Fixed by moving `init` after property declaration. *(Hush)*
- **Debug build support** — `build-release.sh` now accepts `debug` as last argument for assembling debug APKs without re-signing. *(Hush)*
- **Taller mood chips** — home screen mood/genre chips now use 35dp height for better touch targets. *(Hush), adapted from Vivi Music*

## Playback

- **Sleep timer improvements** — `SleepTimer` now accepts a `MusicService` reference. Timer expiry and song-end pause calls `pauseFromSleepTimer()` instead of raw `player.pause()`, properly releasing crossfade resources and pausing both local and cast players. *(Hush), adapted from ArchiveTune*
- **Sleep timer + crossfade** — `scheduleCrossfade()` checks `sleepTimer?.pauseWhenSongEnd` to prevent starting a new crossfade transition when the timer is about to stop. *(Hush), adapted from ArchiveTune*
- **Sleep timer + track transition** — `onMediaItemTransition()` checks `sleepTimer?.pauseWhenSongEnd` and calls `pauseFromSleepTimer()` to stop playback immediately when the sleep timer is set to pause at song end. *(Hush), adapted from ArchiveTune*

## UI

- **Fading edge fix** — horizontal gradient colors for left/right fading edges were swapped (Black at edge instead of Transparent), causing incorrect fade rendering. Fixed by swapping `Color.Black` and `Color.Transparent` positions. *(Hush), adapted from ArchiveTune*
- **Taller mood chips** — `HomeCategoryChips` now renders `FilterChip` at 35dp height instead of the default compact size. *(Hush), adapted from Vivi Music*

## Stability

- **Artist title crash fix** — `?.text!!` in `YouTube.artist()` replaced with `?: "Unknown Artist"` fallback, preventing NPE when YouTube returns an artist response without a title. *(Hush)*
- **Additional `!!` removals** — artist page sections (`?.mapNotNull(...)!!` → `.orEmpty()`) and mood/genres contents (`?.contents!!` → `?.contents.orEmpty()`) now use safe null handling. *(Hush)*
- **LibrarySongsViewModel crash** — `allSongs` Flow was collected in `init` before its declaration, causing NPE. Moved `init` block after `allSongs` declaration. *(Hush)*

## Build

- **Debug APK support** — `scripts/build-release.sh` accepts optional `debug`/`release` last argument. Debug builds use debug shim assemblies and skip APK re-signing. *(Hush)*
- **Clean script improvement** — `clean-build-safe.sh` now removes all Gradle module build directories (`core/`, `canvas/`, `jiosaavn/`, etc.) plus `.gradle/configuration-cache` to prevent stale class files causing D8 errors. *(Hush)*
- **CI fix** — missing `is_internal_rename_commit()` function declaration in `generate-release-notes.sh` causing `local` shell error. *(Hush)*

## Housekeeping

- Version bumped to 13.11.9 (versionCode 159). *(Hush)*
- Waze Bridge shim bumped to versionCode 161. *(Hush)*
